# Mobile-first, poi PWA, poi Capacitor

## Decisione
Sapiens deve funzionare meglio sul dispositivo che lo studente ha in mano, cioè il telefono. L'ordine: layout mobile-first, poi PWA installabile, poi lo stesso codice avvolto con Capacitor per gli store.

## Perché
Un'app nativa riscritta vorrebbe dire una seconda pipeline di contenuti e un secondo sistema di pagamento, e non vale la pena prima che il prodotto dimostri di trattenere gli utenti. Il desktop resta il posto delle sessioni lunghe.
