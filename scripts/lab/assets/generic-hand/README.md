# generic-hand

`left.glb` and `right.glb` are the generic hand meshes of the WebXR Input Profiles project
(github.com/immersive-web/webxr-input-profiles, package `@webxr-input-profiles/assets` 1.0.20,
`dist/profiles/generic-hand`), under the MIT license in `LICENSE.md`.

`build_avatar.py` imports them, fits the avatar's hand and finger bones to their joints and keeps their skin weights.
