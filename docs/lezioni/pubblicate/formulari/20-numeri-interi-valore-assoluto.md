# Formulario: Numeri interi e valore assoluto

## L'insieme ℤ

$$\mathbb{Z} = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\} \qquad \mathbb{N} \subset \mathbb{Z}$$

Positivi: maggiori di $0$. Negativi: minori di $0$. Lo zero non è né positivo né negativo. $+7 = 7$, ma $-7 \neq 7$.

In $\mathbb{Z}$ la sottrazione è sempre possibile: $3 - 8 = -5$.

## Retta orientata

Origine $O$ nello $0$, verso (di solito a destra), unità di misura. Positivi a destra dell'origine, negativi a sinistra.

Successivo: $a + 1$, subito a destra. Precedente: $a - 1$, subito a sinistra. Il successivo di $-5$ è $-4$.

$\mathbb{Z}$ non ha un elemento più piccolo di tutti né uno più grande di tutti.

## Concordi, discordi, opposti

Concordi: stesso segno ($-2$ e $-9$). Discordi: segno diverso ($-4$ e $+6$). Lo zero non è né concorde né discorde con nessun numero.

Opposti: stesso numero di unità, segno diverso. L'opposto di $a$ è $-a$:

$$-(-a) = a \qquad -0 = 0$$

## Valore assoluto

Distanza di $a$ dall'origine: $|5| = |-5| = 5$.

$$|a| = \begin{cases} a & \text{se } a \geq 0 \\ -a & \text{se } a < 0 \end{cases}$$

- $|a| \geq 0$, e $|a| = 0$ solo se $a = 0$.
- $|-a| = |a|$.
- Due interi con lo stesso valore assoluto sono uguali oppure opposti.

## Confronto

$a < b$ quando $a$ sta a sinistra di $b$ sulla retta.

1. Negativi $< 0 <$ positivi.
2. Tra due positivi è maggiore quello con il valore assoluto maggiore: $12 > 7$.
3. Tra due negativi è maggiore quello con il valore assoluto minore: $-7 > -12$.

Ordine crescente: negativi dal valore assoluto maggiore al minore, poi lo zero, poi positivi dal valore assoluto minore al maggiore.

$$-15 < -7 < -1 < 0 < 3 < 4 < 12$$

```ad-warning
Negativi confrontati come positivi
$-12 < -7$, anche se $12 > 7$.
```

```ad-warning
Il segno fuori dalle sbarre
$-|-5| = -5$, non $5$.
```

```ad-warning
Valore assoluto al posto del numero
$|-8| > |3|$, ma $-8 < 3$.
```
