# Formulario: Potenze in ℚ

## Potenza di una frazione

Si elevano alla $n$ sia il numeratore sia il denominatore:

$$\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n} \qquad (b \neq 0)$$

Senza parentesi l'esponente tocca solo il numeratore: $\dfrac{2^2}{3} = \dfrac{4}{3}$, mentre $\left(\dfrac{2}{3}\right)^2 = \dfrac{4}{9}$.

## Segno con base negativa

Con base negativa, esponente pari dà risultato positivo, esponente dispari dà risultato negativo: $\left(-\dfrac{2}{3}\right)^2 = \dfrac{4}{9}$ e $\left(-\dfrac{2}{3}\right)^3 = -\dfrac{8}{27}$.

Le parentesi decidono qual è la base:

$$\left(-\dfrac{2}{3}\right)^2 = +\dfrac{4}{9} \qquad\qquad -\left(\dfrac{2}{3}\right)^2 = -\dfrac{4}{9}$$

## Esponente 1 ed esponente 0

Esponente $1$: $a^1 = a$. Esponente $0$, con base diversa da zero:

$$a^0 = 1 \qquad (a \neq 0)$$

$0^0$ non ha significato. Attenzione al segno fuori: $\left(-\dfrac{5}{7}\right)^0 = 1$, ma $-\left(\dfrac{5}{7}\right)^0 = -1$.

## Esponente negativo

Reciproco della potenza con l'esponente opposto:

$$a^{-n} = \dfrac{1}{a^n} \qquad (a \neq 0)$$

Con una frazione si scambiano numeratore e denominatore e si cambia segno all'esponente:

$$\left(\dfrac{a}{b}\right)^{-n} = \left(\dfrac{b}{a}\right)^n \qquad (a \neq 0,\ b \neq 0)$$

Esempi: $2^{-3} = \dfrac{1}{8}$, $\left(\dfrac{4}{5}\right)^{-1} = \dfrac{5}{4}$, $\left(-\dfrac{1}{2}\right)^{-3} = (-2)^3 = -8$. $0^{-n}$ non ha significato.

Potenze di $10$: $10^{-1} = 0{,}1$, $10^{-2} = 0{,}01$, $10^{-3} = 0{,}001$.

## Proprietà delle potenze

Valgono con esponenti interi qualunque, purché le basi siano diverse da zero.

| Proprietà | Formula | Esempio |
|---|---|---|
| Prodotto, stessa base | $a^m \cdot a^n = a^{m+n}$ | $\left(\frac{2}{3}\right)^2 \cdot \left(\frac{2}{3}\right)^{-5} = \left(\frac{2}{3}\right)^{-3}$ |
| Quoziente, stessa base | $a^m : a^n = a^{m-n}$ | $\left(\frac{3}{4}\right)^5 : \left(\frac{3}{4}\right)^2 = \left(\frac{3}{4}\right)^3$ |
| Potenza di potenza | $\left(a^m\right)^n = a^{m \cdot n}$ | $\left[\left(\frac{1}{2}\right)^3\right]^{-2} = \left(\frac{1}{2}\right)^{-6}$ |
| Prodotto, stesso esponente | $a^n \cdot b^n = (a \cdot b)^n$ | $\left(\frac{2}{3}\right)^3 \cdot \left(\frac{9}{4}\right)^3 = \left(\frac{3}{2}\right)^3$ |
| Quoziente, stesso esponente | $a^n : b^n = (a : b)^n$ | $\left(\frac{5}{6}\right)^2 : \left(\frac{5}{3}\right)^2 = \left(\frac{1}{2}\right)^2$ |

Per la somma e la differenza di potenze non c'è nessuna proprietà.

```ad-warning
L'esponente negativo non rende negativo il risultato
$2^{-3} = \dfrac{1}{8}$, non $-8$ né $-\dfrac{1}{8}$: il segno dipende solo dalla base e dall'esponente pari o dispari.
```

```ad-warning
Il reciproco non cambia il segno della base
$\left(\dfrac{2}{3}\right)^{-3} = \left(\dfrac{3}{2}\right)^3 = \dfrac{27}{8}$, non $\left(-\dfrac{3}{2}\right)^3$.
```

```ad-warning
Niente somma di esponenti in una somma
$\left(\dfrac{1}{2}\right)^2 + \left(\dfrac{1}{2}\right)^3 = \dfrac{1}{4} + \dfrac{1}{8} = \dfrac{3}{8}$, non $\left(\dfrac{1}{2}\right)^5$.
```
