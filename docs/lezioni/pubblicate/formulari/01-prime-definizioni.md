# Formulario: Prime definizioni

## Insieme ed elementi

Un insieme è una collezione di oggetti ben definita: per ogni oggetto si può dire, in modo oggettivo, se ne fa parte oppure no. Gli oggetti che ne fanno parte sono i suoi elementi.

Ogni elemento conta una volta sola e l'ordine non conta: le lettere di "matematica" sono m, a, t, e, i, c.

## Notazione

Insiemi con le maiuscole, elementi con le minuscole, elencazione tra graffe:

$$A = \{1, 2, 3, 4\}$$

| Simbolo | Insieme |
|---|---|
| $\mathbb{N}$ | numeri naturali $0, 1, 2, 3, \dots$ (lo $0$ è compreso) |
| $\mathbb{Z}$ | numeri interi relativi $\dots, -2, -1, 0, 1, 2, \dots$ |
| $\mathbb{Q}$ | numeri razionali, quelli che si scrivono come frazione |
| $\mathbb{R}$ | numeri reali |

## Appartenenza

Appartiene a, non appartiene a (a sinistra un elemento, a destra un insieme):

$$3 \in \{1, 2, 3, 4\} \qquad 7 \notin \{1, 2, 3, 4\}$$

## Insiemi particolari

Insieme vuoto, senza elementi, ed è uno solo:

$$\emptyset = \{\ \}$$

Insieme unitario: ha un solo elemento, come $\{0\}$.

Insieme universo $U$: l'insieme da cui si prendono gli elementi, fissato dal problema.

## Finiti, infiniti e cardinalità

Un insieme è finito se contando i suoi elementi a un certo punto si finisce, altrimenti è infinito. La cardinalità di un insieme finito è il numero dei suoi elementi:

$$|A| \qquad \text{(anche } \text{card}(A) \text{ o } n(A)\text{)}$$

Per esempio $|\{1, 2, 3, 4\}| = 4$ e $|\emptyset| = 0$; $\mathbb{N}$ è infinito.

```ad-warning
$\emptyset$ non è $\{0\}$
$\{0\}$ ha un elemento, il numero 0: la sua cardinalità è 1, quella di $\emptyset$ è 0.
```

```ad-warning
Lo 0 è naturale
$0 \in \mathbb{N}$: i numeri naturali minori di 5 sono cinque, 0, 1, 2, 3, 4.
```

```ad-warning
Elementi ripetuti
Le lettere di "cocco" formano un insieme di 2 elementi, c e o, non di 5.
```
