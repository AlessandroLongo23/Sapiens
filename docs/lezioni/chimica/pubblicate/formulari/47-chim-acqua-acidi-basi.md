# Formulario: Soluzioni acide e basiche: una prima idea del pH

## Acidi e basi

| | Acidi | Basi |
|---|---|---|
| sapore | aspro | amaro, scivolose al tatto |
| tornasole | rosso | blu |
| con i metalli (zinco, magnesio) | idrogeno | |
| con il calcare | anidride carbonica | |
| esempi | $\mathrm{HCl}$, $\mathrm{H_2SO_4}$, $\mathrm{HNO_3}$, $\mathrm{CH_3COOH}$ | $\mathrm{NaOH}$, $\mathrm{KOH}$, $\mathrm{Ca(OH)_2}$, $\mathrm{NH_3}$ |

Le soluzioni di acidi e di basi conducono la corrente.

## Arrhenius

- Acido: in acqua libera ioni $\mathrm{H^+}$. $\mathrm{HCl}(g) \longrightarrow \mathrm{H^+}(aq) + \mathrm{Cl^-}(aq)$
- Base: in acqua libera ioni $\mathrm{OH^-}$. $\mathrm{NaOH}(s) \longrightarrow \mathrm{Na^+}(aq) + \mathrm{OH^-}(aq)$
- Acqua pura: $\mathrm{H_2O} \rightleftarrows \mathrm{H^+} + \mathrm{OH^-}$, una molecola ogni $550$ milioni circa; ioni uguali, neutra.
- Acida: più $\mathrm{H^+}$ che $\mathrm{OH^-}$. Basica: più $\mathrm{OH^-}$ che $\mathrm{H^+}$.
- Neutralizzazione: $\mathrm{H^+} + \mathrm{OH^-} \longrightarrow \mathrm{H_2O}$; acido più base danno un sale e acqua.

## Scala del pH (a 25 °C)

- $\text{pH} < 7$ acida, $\text{pH} = 7$ neutra, $\text{pH} > 7$ basica.
- Un'unità di pH in meno: dieci volte più ioni $\mathrm{H^+}$. Una differenza di $n$ unità: $10^n$ volte.
- Cenno: $[\mathrm{H^+}] = 10^{-\text{pH}}\,\text{mol/L}$, cioè $\text{pH} = -\log[\mathrm{H^+}]$.
- Acido forte diluito $10$ volte: pH $+1$; base forte: pH $-1$. Diluendo ci si avvicina a $7$ senza superarlo.

## Indicatori

| Indicatore | Acido | Basico |
|---|---|---|
| tornasole | rosso (sotto $4{,}5$) | blu (sopra $8{,}3$) |
| fenolftaleina | incolore (fino a $8{,}2$) | rosa acceso (sopra $10$) |
| universale | rosso $0$-$2$, arancione $3$-$4$, giallo $5$-$6$ | verde $7$, blu $8$-$10$, viola $11$-$14$ |
| cavolo rosso | rosso, rosa | blu, verde, giallo |

```ad-warning
Più piccolo, più acido
Un pH più basso vuol dire una soluzione più acida, e due unità di differenza sono un fattore $100$.
```

```ad-warning
Incolore non vuol dire neutro
La fenolftaleina resta incolore anche nelle soluzioni acide.
```

```ad-warning
Diluire non fa cambiare natura
Un acido diluito resta acido: il pH sale verso $7$ ma non lo supera.
```
