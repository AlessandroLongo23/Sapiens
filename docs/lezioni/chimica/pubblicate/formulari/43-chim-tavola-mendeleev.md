# Formulario: La tavola periodica di Mendeleev

## Prima di Mendeleev

- Triadi di Döbereiner (1829): la massa dell'elemento centrale è vicina alla media delle altre due (litio, sodio, potassio: $(6{,}94 + 39{,}10)/2 = 23{,}02$).
- Ottave di Newlands (1865): le proprietà si ripetono ogni otto elementi, solo per i più leggeri.

## La tavola di Mendeleev (1869)

- Elementi in ordine di massa atomica crescente, elementi simili nella stessa colonna.
- Gruppi: le colonne, elementi con proprietà simili. Periodi: le righe.
- Legge periodica: ordinati, gli elementi ripetono le proprietà a intervalli regolari.
- Caselle vuote per gli elementi da scoprire: eka-alluminio (gallio, 1875), eka-boro (scandio, 1879), eka-silicio (germanio, 1886).
- Inversioni per rispettare le proprietà: tellurio prima dello iodio.

## Prevedere per analogia

- Una massa che manca: la media tra l'elemento sopra e quello sotto nello stesso gruppo.
- Le formule: elementi dello stesso gruppo formano composti con la stessa formula ($\mathrm{Na_2O}$, $\mathrm{K_2O}$; $\mathrm{SiO_2}$, $\mathrm{SnO_2}$, $\mathrm{GeO_2}$).

## La tavola moderna

- Moseley (1913): gli elementi si ordinano per numero atomico $Z$; le inversioni spariscono (tellurio $Z = 52$, iodio $Z = 53$).
- Sette periodi, diciotto gruppi. Gruppo $1$ metalli alcalini, $2$ alcalino-terrosi, $17$ alogeni, $18$ gas nobili.
- Coppie invertite rispetto alla massa: argon e potassio, cobalto e nichel, tellurio e iodio.

```ad-warning
Massa o numero atomico
Mendeleev ordinava per massa atomica; per numero atomico si ordina dal 1913.
```

```ad-warning
Colonna, non riga
Le proprietà simili sono quelle degli elementi dello stesso gruppo.
```
