# Formulario: La legge di Proust

## Proporzioni definite e costanti

In un composto le masse degli elementi stanno sempre nello stesso rapporto, il rapporto di combinazione:

$$\frac{m_{\mathrm{Cu}}}{m_{\mathrm{S}}} = 3{,}96 \quad \text{(solfuro di rame)}$$

| Composto | Rapporto di combinazione |
|---|---|
| Solfuro di rame | $m_{\mathrm{Cu}} / m_{\mathrm{S}} = 3{,}96$ |
| Solfuro di ferro | $m_{\mathrm{Fe}} / m_{\mathrm{S}} = 1{,}74$ |
| Ossido di magnesio | $m_{\mathrm{Mg}} / m_{\mathrm{O}} = 1{,}52$ |
| Acqua | $m_{\mathrm{O}} / m_{\mathrm{H}} = 7{,}92$ |
| Cloruro di sodio | $m_{\mathrm{Cl}} / m_{\mathrm{Na}} = 1{,}54$ |
| Diossido di carbonio | $m_{\mathrm{O}} / m_{\mathrm{C}} = 2{,}66$ |

- Dal rapporto: $m_{\mathrm{S}} = m_{\mathrm{Cu}} / 3{,}96$ e $m_{\mathrm{Cu}} = 3{,}96 \cdot m_{\mathrm{S}}$.
- La massa di un elemento è direttamente proporzionale a quella dell'altro.

## Composizione percentuale

$$\%\,\text{elemento} = \frac{m_{\text{elemento}}}{m_{\text{composto}}} \cdot 100$$

Solfuro di rame: $79{,}8\%$ di rame, $20{,}2\%$ di zolfo. Acqua: $11{,}2\%$ di idrogeno, $88{,}8\%$ di ossigeno.

## Reagente in eccesso

1. Si scrive il rapporto di combinazione.
2. Si calcola quanto del secondo elemento servirebbe per tutto il primo.
3. Se ce n'è di più, il secondo è in eccesso; se ce n'è di meno, è in eccesso il primo, e si riparte dal secondo.
4. Avanza: massa disponibile meno massa che reagisce.
5. Prodotto: somma delle masse che reagiscono.

```ad-warning
Il rapporto rovesciato
Con $m_{\mathrm{Cu}}/m_{\mathrm{S}} = 3{,}96$, lo zolfo per $12{,}0\,\text{g}$ di rame è $12{,}0 / 3{,}96 = 3{,}03\,\text{g}$, non $12{,}0 \cdot 3{,}96$.
```

```ad-warning
L'eccesso non è la massa più grande
Si confronta ogni massa con quella che il rapporto richiede, non le due masse tra loro.
```

```ad-warning
Il prodotto non è la somma dei reagenti messi
Il reagente in eccesso resta com'è e non entra nel composto.
```
