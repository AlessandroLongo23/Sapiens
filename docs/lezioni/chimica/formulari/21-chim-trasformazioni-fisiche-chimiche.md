# Formulario: Trasformazioni fisiche e trasformazioni chimiche

## Due tipi di trasformazione

| | Trasformazione fisica | Trasformazione chimica |
|---|---|---|
| Sostanze alla fine | le stesse dell'inizio | sostanze nuove, con proprietà diverse |
| Esempi | passaggi di stato, sciogliere, macinare, separare un miscuglio | combustione, ruggine, cottura, fermentazione, digestione |

## Reazione chimica

- Reagenti: le sostanze di partenza. Prodotti: le sostanze che si formano.
- Si scrive a parole: $\text{reagenti} \longrightarrow \text{prodotti}$, per esempio $\text{ferro} + \text{zolfo} \longrightarrow \text{solfuro di ferro}$.

## Gli indizi di una reazione

1. Si sviluppa un gas (effervescenza).
2. Si forma un precipitato, un solido in un liquido limpido.
3. Cambia il colore.
4. Si libera o si assorbe energia: calore, luce.
5. Compare un odore nuovo.

Un indizio non è una prova: decide la formazione di sostanze nuove.

## Energia

- Esotermica: la reazione libera calore (combustioni).
- Endotermica: la reazione assorbe calore (decomposizione del calcare).

```ad-warning
Bollicine non vuol dire reazione
L'acqua che bolle fa bollicine di vapore acqueo: è ancora acqua, la trasformazione è fisica.
```

```ad-warning
Irreversibile non vuol dire chimica
Un bicchiere rotto non si ricompone, ma è ancora vetro: la trasformazione è fisica.
```

```ad-warning
Sciogliere non è reagire
Lo zucchero sciolto nell'acqua è ancora zucchero.
```
