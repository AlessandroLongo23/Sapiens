# Formulario: Il cloud: archiviare, condividere e lavorare insieme

## Che cos'è il cloud

- Cloud computing: l'uso, attraverso Internet, di risorse di computer remoti (spazio per i file, programmi, capacità di calcolo), offerte come un servizio.
- Data center: l'edificio che ospita migliaia di server, sempre accesi.
- I tuoi dispositivi fanno da client; ogni file è registrato in più copie su macchine diverse.

## Archiviare

- Archiviazione nel cloud (cloud storage): uno spazio sui server di un fornitore, legato al tuo account, in cui tenere i file.
- Lo spazio ha un limite: quando finisce, i file nuovi non vengono caricati.
- Quanti file stanno nello spazio: con $1\,\text{GB} = 1000\,\text{MB}$, in $5\,\text{GB}$ stanno $5000 : 4 = 1250$ foto da $4\,\text{MB}$.
- Sincronizzazione: il meccanismo che tiene uguali la copia sul dispositivo e la copia sul server, e porta ogni modifica a tutti i dispositivi dell'account.
- Senza connessione la modifica resta sul dispositivo e parte quando la rete torna; se due versioni sono in conflitto, di solito il servizio le conserva entrambe.

## Condividere

- Condividere: dare ad altri l'accesso allo stesso file, che resta nel tuo spazio. Non parte nessuna copia.
- Invito: solo le persone indicate, entrando con il proprio account. Link: chiunque lo possieda.

| Permesso | Che cosa permette | Quando usarlo |
|---|---|---|
| lettura | aprire e leggere | far vedere un lavoro finito |
| commento | leggere e commentare a margine | chiedere un parere o una correzione |
| modifica | cambiare il contenuto | lavorare insieme |

- A ciascuno il permesso più basso che gli basta.

## Lavorare insieme

- Un solo file per tutti, al posto di tante copie spedite come allegati.
- Più persone scrivono nello stesso momento; il salvataggio è continuo.
- Cronologia delle versioni: l'elenco degli stati precedenti del file, con data e autore di ogni modifica; una versione vecchia si può riaprire e ripristinare.
- Applicazione web: un programma che usi dal browser senza installarlo; dati e buona parte dell'elaborazione stanno sul server.

## Vantaggi e limiti

| Vantaggi | Limiti |
|---|---|
| file raggiungibili da qualunque dispositivo collegato | senza connessione solo i file già scaricati |
| i file restano se il dispositivo si rompe | spazio gratuito limitato |
| più persone sullo stesso file | i dati stanno sui computer di un'azienda |
| niente da installare né da aggiornare | chi entra nell'account entra in tutti i file |

```ad-warning
Sincronizzare non è fare una copia di sicurezza
Se cancelli un file sincronizzato da un dispositivo, sparisce anche dal cloud e dagli altri dispositivi.
```

```ad-warning
Un link aperto a chiunque non è privato
Il link si copia e si inoltra: per i dati personali usa l'invito a persone precise.
```

```ad-warning
Ripristinare una versione vecchia toglie il lavoro fatto dopo
Per recuperare un pezzo, copialo dalla versione vecchia e incollalo in quella di oggi.
```
