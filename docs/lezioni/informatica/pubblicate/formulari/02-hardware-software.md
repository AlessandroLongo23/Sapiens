# Formulario: Hardware e software

## Hardware e software

- Hardware: l'insieme dei componenti fisici di un computer, tutto quello che si può toccare (schermo, batteria, tastiera, CPU, memoria RAM).
- Programma: una sequenza di istruzioni che dice all'hardware che cosa fare.
- Software: l'insieme dei programmi di un computer.
- I documenti, le foto e la musica sono dati: non si toccano, ma non sono programmi.
- Il disco di un videogioco è hardware; il gioco registrato sopra è software.

## Tipi di software

| Tipo | A che cosa serve | Esempi |
|---|---|---|
| software di base (di sistema) | gestisce l'hardware e lo rende utilizzabile dagli altri programmi | sistema operativo, driver |
| software applicativo | serve all'utente per fare il suo lavoro | videoscrittura, foglio di calcolo, browser, videogiochi, app |

- Sistema operativo: parte all'accensione e resta in esecuzione; assegna CPU e memoria ai programmi, organizza i file, mostra finestre e icone.
- Driver: il programma che permette al sistema operativo di usare una periferica precisa (quella stampante, quella webcam).
- Firmware: il software registrato in modo permanente in un chip del dispositivo; è il primo a partire all'accensione.
- Gli strati, dall'alto: utente, software applicativo, software di base, hardware. Ognuno parla solo con quello vicino.

## Guasti e problemi

| | Hardware | Software |
|---|---|---|
| Con il tempo | si consuma e si rompe | non si consuma, ma può contenere errori |
| Rimedio | si ripara o si sostituisce il pezzo | si aggiorna o si reinstalla il programma |
| Copia | no | sì, identica all'originale |

## Licenze

- Licenza: il contratto che dice che cosa si può fare con un programma.
- Software proprietario: si usa, ma non si può studiare né modificare.
- Software libero (open source): si può usare, studiare, modificare e ridistribuire.
- Freeware: software proprietario che si usa gratis.

```ad-warning
Dentro il computer non vuol dire software
La CPU e la memoria RAM non si vedono, ma sono oggetti: sono hardware.
```

```ad-warning
Firmware e driver sono software
Il chip è hardware, il programma scritto nel chip è software; il driver è un programma installato sul computer, non un pezzo della periferica.
```

```ad-warning
Gratis non vuol dire libero
Un programma gratuito che nessuno può studiare o modificare è freeware, non software libero.
```
