# Formulario: La composizione dei moti

## Moti indipendenti

- Un moto nel piano è la somma di due moti rettilinei lungo $x$ e lungo $y$, con lo stesso tempo $t$.
- Due moti uniformi: il moto composto è rettilineo uniforme, con $v = \sqrt{v_x^2 + v_y^2}$.

## Velocità relativa

$$\vec{v}_{\text{rispetto al pavimento}} = \vec{v}_{\text{rispetto al tapis roulant}} + \vec{v}_{\text{del tapis roulant}}$$

- Stessa direzione e stesso verso: i moduli si sommano. Versi opposti: si sottraggono.

## Barca sul fiume

$$\vec{v} = \vec{v}_b + \vec{v}_c$$

| | Prua perpendicolare alla riva | Prua controcorrente di $\alpha$ |
|---|---|---|
| Velocità rispetto alla riva | $v = \sqrt{v_b^2 + v_c^2}$ | $v = \sqrt{v_b^2 - v_c^2}$ |
| Direzione | $\tan\beta = v_c/v_b$ | perpendicolare alla riva, con $\sin\alpha = v_c/v_b$ |
| Tempo per attraversare | $t = d/v_b$ | $t = d/v$ |
| Dove arriva | $v_c\,t$ a valle | di fronte alla partenza |

- Arrivare di fronte si può solo se $v_b > v_c$.

```ad-warning
Il tempo con la prua dritta
$t = d/v_b$, non $d/v$: la corrente sposta la barca ma non la rallenta.
```

```ad-warning
Seno o tangente
Prua controcorrente: $\sin\alpha = v_c/v_b$. Prua perpendicolare: $\tan\beta = v_c/v_b$.
```

```ad-warning
Le velocità sono vettori
Con direzioni diverse il modulo della somma non è la somma dei moduli.
```
