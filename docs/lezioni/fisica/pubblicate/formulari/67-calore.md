# Formulario: Calore, capacità termica e calore specifico

## Il calore

- Il calore $Q$ è energia che passa per una differenza di temperatura, dal corpo più caldo al più freddo; si misura in joule.
- Esperimento di Joule: il lavoro scalda l'acqua come il calore.

$$1\,\text{cal} = 4{,}186\,\text{J} \qquad 1\,\text{kcal} = 1000\,\text{cal} = 4186\,\text{J}$$

## Capacità termica e calore specifico

$$C = \frac{Q}{\Delta t} \qquad C = c\,m$$

$$Q = c\,m\,\Delta t$$

- $C$ in $\text{J}/^\circ\text{C}$, proprietà dell'oggetto; $c$ in $\text{J/(kg}\cdot{}^\circ\text{C)}$, proprietà del materiale.
- Più corpi scaldati insieme: le capacità termiche si sommano.
- $\Delta t = t_f - t_i$: $Q > 0$ il corpo assorbe, $Q < 0$ cede.

| Sostanza | $c$ in $\text{J/(kg}\cdot{}^\circ\text{C)}$ |
|---|---|
| acqua | $4186$ |
| alcol etilico | $2440$ |
| olio d'oliva | $1970$ |
| alluminio | $897$ |
| vetro | $840$ |
| ferro | $449$ |
| rame | $385$ |
| piombo | $129$ |

- Acqua: $c = 1\,\text{cal/(g}\cdot{}^\circ\text{C)}$.
- Stesso $Q$, stessa $m$: $\dfrac{\Delta t_1}{\Delta t_2} = \dfrac{c_2}{c_1}$ (l'olio si scalda circa il doppio dell'acqua).

```ad-warning
Calore e temperatura
La temperatura dice quanto un corpo è caldo; il calore è energia che passa, in joule.
```

```ad-warning
La massa in chilogrammi
Con $c$ in $\text{J/(kg}\cdot{}^\circ\text{C)}$ i grammi vanno convertiti.
```

```ad-warning
Il calore dà $\Delta t$
$Q/(c\,m)$ è l'aumento di temperatura: la temperatura finale è $t_i + \Delta t$.
```
